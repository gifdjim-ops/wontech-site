# Бето Инкам B2B-каталог

Многостраничный сайт-каталог бурового инструмента для заявок на расчет. Бето Инкам указана как компания, WONTECH - как бренд бурового инструмента в карточках.

## Структура

- `index.html` - главная страница.
- `catalog.html` - общий каталог.
- `availability.html` - популярные позиции для проверки наличия.
- `category-*.html` - страницы категорий.
- `products/*.html` - карточки позиций.
- `articles/*.html` - большие статьи на отдельных страницах.
- `logistics.html` - Яндекс.Карта и поставки.
- `specification.html` - отправка спецификации.
- `contacts.html` - контакты и команда.
- `gallery.html` - фотографии.
- `documents.html` - документы сайта.

## Telegram

Форма отправляет заявки через серверный обработчик `/api/request`.

Токен нельзя хранить в HTML, CSS или JS. Для локальной настройки используется `telegram.local.json`.

1. Создать новый токен в BotFather.
2. Вставить его в `telegram.local.json`.
3. Написать любое сообщение боту от нужных Telegram-аккаунтов.
4. Перезапустить сайт.

Для нескольких получателей используется `telegramChatIds` через запятую или пробел.

`telegram.local.json` не нужно публиковать и отправлять клиентам.

